# AurelRide

An open-world stylized 3D cycling experience built with **Three.js**, custom **GLSL shaders**, and procedural **Web Audio** — running directly in the browser with no download or installation required.

**Play Now:** https://henryshi11.github.io/aurelride/

## Highlights

- **360° Living Alpine Skyline**: A unified 5-layer horizon lit by a fixed southeast world sun — featuring the White City, Ornate Twin White Rings, wide multi-layer mountain transitions, Southwest Turquoise Waterfall Gorge, Eastern Snow Sanctuary with animated portal light, soaring distant dragon, and drifting shader-driven clouds & valley mist.
- **Tactile Riding & Biome World**: Explore sunlit emerald meadows, lavender & canola fields, cherry petal orchards, high silvergrass plateaus, an eastern snowfield, a rideable monolithic white-stone fortress wall, and splash straight through the river at high speed with dynamic V-spray wakes and biome-specific tire tracks.
- **Fluid Camera & Physics**: Full 360° free mouse orbit, optional pointer-lock (`Tab` / middle-click), 4 cinema camera presets (`1-4`), `Shift` sprint pedaling, Verlet cloth cape simulation, and procedural biome ASMR audio.
- **Web & Low-End PC Optimizations**: All vista textures compressed to WebP, scripts bundled & minified into a single `aurelride.min.js` payload, hardware-aware Eco mode + live toolbar quality toggle, and real-time Dynamic Resolution Scaling (DRS).

## Controls

| Input | Action |
| :--- | :--- |
| `W / S` or `↑ / ↓` | Pedal / Brake |
| `A / D` or `← / →` | Steer |
| `Shift` | Sprint Boost |
| `Mouse Drag` / `Scroll` | 360° Free Orbit / Zoom |
| `Tab` or `Middle Click` | Toggle Pointer-Lock Camera |
| `1 / 2 / 3 / 4` | Cinema Camera Presets |
| `L` | Lock / Unlock Custom Camera Angle |
| `G` / `B` / `V` | World Map / Rider & Bike Outfitter / Quick Outfit |
| `Space` / `R` / `M` | Pause / Reset / Mute Audio |
