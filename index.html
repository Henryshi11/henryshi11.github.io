Try a prompt for Jumping Ball Runner

Original practice prompt · A chalkboard runner

Build a one-button game in a single HTML file. A chalk dot rolls across a blackboard. Let the player press Space or tap to jump over erasers. Score one point for each eraser cleared. Give the first three jumps equal spacing. After that, vary the gaps while keeping every jump reachable. On a collision, freeze for half a second and show a Retry button. Replay the same opening sequence so the player can learn its rhythm. Draw everything with Canvas. Put the score in the corner and make Retry work with a keyboard or a tap. Return the complete HTML file.

Try a prompt for WebGL Aquarium

Original practice prompt · A pocket aquarium

Create a small 2D fish tank in one self-contained HTML file. Draw two schools of fish with simple shapes. Give each school its own color and cruising speed. Add controls for 8, 32 and 96 fish, plus a Pause button. When the count goes up, have new fish swim in from the edges while the others keep their positions. Pause should freeze the entire tank until I press it again. Use Canvas and plain JavaScript. On a phone, place the controls below the tank and keep them reachable by keyboard. Return the complete HTML file.
